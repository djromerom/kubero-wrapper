# Identidad visual · Atlas

Atlas sostiene los proyectos que nacen en la Universidad del Norte. La identidad usa la paleta facilitada para el proyecto; no pretende sustituir el escudo ni constituir un manual oficial de la Universidad.

## Paleta

| Color | Token | Uso |
| --- | --- | --- |
| #1D1D1B | atlas-ink | Texto principal, símbolo y hover de acciones |
| #A00000 | atlas-red | Acciones principales, navegación activa, enlaces y panel de acceso |
| #FF3010 | atlas-accent | Esfera del isotipo y acentos decorativos |
| #EBEBEB | atlas-mist | Fondo de trabajo, campos y separadores |
| #FFFFFF | atlas-paper | Tarjetas, formularios y texto sobre rojo oscuro |

El gris auxiliar #62625E se usa en textos secundarios. El rojo brillante se reserva para decoración: no se utiliza como texto pequeño sobre blanco ni como fondo de botones con texto blanco. Los colores semánticos de estado se mantienen separados de la marca y siempre acompañados de etiquetas.

## Composición

Tipografía de sistema Segoe UI con alternativas Arial/sans-serif, sin dependencia de fuentes externas. Navegación lateral blanca, área de trabajo gris, tarjetas blancas y acciones en rojo oscuro. El acceso combina una sección editorial roja con un formulario blanco. Foco visible y adaptación móvil.

## Tres direcciones para el isotipo

1. **A que sostiene una esfera — propuesta aplicada.** La inicial forma dos apoyos y un arco de hombros. Una esfera naranja representa el proyecto sostenido. Relaciona el nombre, el titán y la plataforma; funciona en una tinta y como favicon.
2. **Órbita sobre un pedestal.** Una esfera atravesada por una órbita descansa sobre una base abierta. Expresa continuidad, despliegue y soporte; tiene un carácter más tecnológico.
3. **Bóveda modular.** Tres bloques forman un arco que sostiene un punto. Evoca proyectos independientes sobre infraestructura compartida, con una silueta geométrica sencilla.

La primera opción fue elegida: A que sostiene una esfera. Ver [lámina comparativa](atlas-isotypes.svg). La dirección queda definida; se pueden refinar proporciones y espaciado en tamaños pequeños.
